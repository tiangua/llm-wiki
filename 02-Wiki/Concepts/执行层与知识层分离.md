# 执行层与知识层分离

## 编译真相
> 长跑 Agent 系统里，**负责干活的那层要允许回滚，负责记住的那层不允许回滚**。回滚只回滚执行层，知识层只增不减——这是「越用越好」在工程上唯一可落地的形态。

## 核心定义

把 Agent 的运行时状态切成两个语义相反的层：

| 层 | 语义 | 回滚行为 | 内容形态 |
|---|---|---|---|
| **执行层** | 当前生效、直接驱动行为 | **可变、可回滚** | 技能集、执行状态、prompt |
| **知识层** | 跨迭代/跨任务沉淀的教训 | **只增、永不回滚** | 失败模式、策略、提案历史 |

二者的接口是**单向的**：知识层 → 执行层（编译/注入），执行层的失败 → 知识层（记账）。执行层的回滚**绝不级联**到知识层。

## 关键要点

### 1. 复利的唯一来源是「失败不清零」

普通自进化方法的根本毛病是**每轮都从零开始猜**：提案被拒就丢弃，下一轮重来，上一轮的教训沉没在优化历史里。

分离式设计只需一处改造，但很致命——**门控拒绝时，执行层回滚，知识层不回滚**。被拒的提案连同它的 diff、验证分数、被拒结论原样记账进知识层。下一轮拿到的不是白纸，而是一张「什么试过、为什么失败」的地图。

实证（[[WikiSkill]] 消融，Gemini-3.5-Flash，4 基准平均）：

| 配置 | 平均分 |
|---|---|
| 无知识层（且无维护者） | 48.7 |
| 有知识层（仅提案者可访问） | **63.7** |

**这 15.0 个点，就是「积累」本身的贡献**——同样的提案器、同样的门控，仅因多了一层不回滚的知识就拉开差距。

### 2. 两种形态，同一原则

| | 执行层（可变） | 知识层（不可变/只增） |
|---|---|---|
| **[[WikiSkill]]**（跨迭代） | `skills/` 技能集，可回滚到上一成功版本 | `wiki/` — patterns + logs + skill-impact，**永不回滚** |
| **[[SKILL.state]]**（单步内） | `Σ_t` 执行状态，每步增量合并 | 无（单步内不需要）—— 但**被丢弃的推理 R 也不回滚，而是直接消失** |

SKILL.state 是同一原则在**时间轴压缩到单步**时的形态：执行状态 Σ 可变且每步被校验修正，推理轨迹 R 用完即弃，绝不回流。

### 3. 与相邻做法的区别

| 做法 | 与分离式的差别 |
|---|---|
| **对话历史 / 日志** | 只增不减但**非结构化**，无法被系统性检索复用；且会污染上下文 |
| **摘要压缩** | 执行层与知识层混在一起，压缩是有损的——[[SKILL.state]] 的预算匹配实验显示，同等 token 预算下滑窗截断只有 0.18、LLMLingua 0.22，而结构化状态 0.94 |
| **模型微调 / 持续学习** | 知识直接写进权重，无法回滚、无法审计、有灾难性遗忘 |
| **RAG 外部知识库** | 只解决「查什么」，不解决「做过什么、失败过什么」的记账 |

### 4. 工程落地检查清单

- [ ] **执行层可原子回滚**：每个改动是一个可撤销的 diff，而非对整体的覆盖
- [ ] **知识层不级联回滚**：门控失败时，明确区分「回滚执行」与「记录知识」两个动作
- [ ] **知识层可被检索，而非被整包注入**——[[WikiSkill]] 给 Proposer 的是索引 + 按需工具调用，不是全文倾倒
- [ ] **schema 所有权与校验在确定性运行时**，不在模型里（畸形输出不能破坏持久状态）
- [ ] **知识层设采样预算与容量上限**（论文自陈 [[WikiSkill]] 缺自动剪枝，长跑会膨胀）

### 5. 风险与反例

| 风险 | 说明 | 缓解 |
|---|---|---|
| **知识层膨胀** | 只增不剪，长跑后检索质量下降 | 需自动剪枝/合并机制（两篇论文都未解决） |
| **记账记歪** | 门控依赖验证集；无 ground truth 时，错误结论会被永久记入 | 先有可判定的验证函数，再谈知识层 |
| **充分统计假设失效** | 相关信息若未被及时投影进状态，丢弃即永久丢失 | 参见 [[SKILL.state]] 的三种失效场景 |
| **小模型执行不了** | 知识层产出的策略超出模型执行能力时会退化 | [[WikiSkill]] 中 Qwen-3.5-4B 在 OfficeQA 上 28.5% 反低于无技能 30.2% |
| **天花板效应** | 任务已饱和时机制不产出任何东西 | 有早停机制即可，无需强演化 |
